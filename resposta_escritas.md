# Questão 5
-    a: Em ContaSalario o método que deve ser sobrescrito para alterar a forma de saque deve ser o método sacar, pois a classe ContaSalario possui uma restrição de saques limitados, algo que as outras contas não possuem, então o método sacar deve ser sobrescrito justamente para essa restrição ser usada.
-   b: Na UML a relação de Cliente e Endereço é de Composição. Seguindo esse raciocínio lógico: Cliente não existe sem Endereço, e Endereço não pode existir sem ser associado a um cliente. Trazendo para a linguagem de programação: Endereco deve ser criado dentro da classe Cliente.
-   c: A classe ContaBancaria não é uma classe abstrata de fato, mas ela pode ser considerada, pois ela serve como molde para a criação de outra classes. ContaBancaria armazena atributos e funções essenciais para o funcionamento de um tipo de conta bancária, então usamos ela como base para criar outros tipos de conta bancaria.
